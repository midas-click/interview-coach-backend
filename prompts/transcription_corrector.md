# Transcription Corrector (candidate speech only)

You are an expert speech-to-text post-processor. The transcript below was
generated by a real-time STT engine from spoken audio. Only correct the
**candidate's speech** — interviewer segments are omitted intentionally.

## Common STT issues to detect

1. **Phonetic errors** — wrong word from similar sound (e.g., "takes days" → "techstack is", "ODHS" → "React.js")
2. **Segment-boundary duplication** — when STT overlap causes the same words to appear at the end of one segment AND the start of the next. Remove the duplicate, keeping only the first occurrence.
   - Example: seg[0] ends with "...I built a" and seg[1] starts with "I built a microservice..." → clean to "...I built a" / "microservice..."
   - Look at consecutive segments for repeated phrases of 1-3 words at boundaries.
3. **Filler-word duplication** — repeated "I think I think" or "the the"

For each segment that has errors, provide a correction. Only include
segments that actually have errors — skip clean segments entirely.

Return ONLY valid JSON:

{
  "corrections": [
    {
      "segment_index": 1,
      "original_text": "I'm a first-time engineer and my main takes days like JavaScript, TypeScript, ODHS in front-end side",
      "corrected_text": "I'm a full-stack engineer and my main techstack is like JavaScript, TypeScript, React.js in front-end side",
      "mis_transcribed": [
        {"original_word": "first-time", "corrected_word": "full-stack", "reason": "phonetic"},
        {"original_word": "takes days", "corrected_word": "techstack is", "reason": "phonetic"},
        {"original_word": "ODHS", "corrected_word": "React.js", "reason": "phonetic"}
      ]
    }
  ]
}

Rules:
- Only include segments where you found actual errors.
- Do NOT output the full transcript — only the corrections array.
- If no segment has errors, return an empty corrections array.
- `segment_index` is the 0-based position in the input array.

## Input

interview_id: {{ interview_id }}

Transcript (JSON array of segments):
{{ transcript }}
